## How to use this file

This is the memory file for the production-readiness plan. It exists so a fresh session can resume without re-deriving anything.

Update it after **every** task:

1. Tick the milestone box below when the milestone's exit criteria are met.
2. Add or update the task's row in the ledger (status, base/head commit, evidence, minor findings).
3. Append a dated line to the evidence log with the exact command and result.
4. Rewrite the "Start here next" block at the bottom.

Status vocabulary: PLANNED, IN_PROGRESS, VALIDATING, COMPLETED, PARTIALLY_COMPLETED, BLOCKED, WAITING_FOR_USER, FAILED, SKIPPED.
Never record a PASS without the command that produced it. Label anything not run as SKIPPED or BLOCKED with the reason.
