# شورى · Shura

**Ask one question. Hear from many models. Side by side, as they think.**

A local-first Arabic (RTL) chat app that sends a single prompt to several AI providers **in parallel**
and streams every answer into its own card, ready to compare. No backend and no middleman: your
keys go only to the provider they belong to.

## Highlights

| | |
|---|---|
| ⚡ **Parallel dispatch** | One shared question for every model, or a custom question per model (shared + custom are joined; custom alone works too). |
| 📡 **Live streaming** | Each provider streams into its own card, with tokens, cache hits and cost per answer. Toggle vertical or horizontal layout; the choice is saved. |
| 🧠 **Synthesis** | "استخرج خلاصة" (Extract a summary) sends the last round to the session's primary model and returns one combined answer. |
| 🗂️ **Stateful or stateless** | Sessions carry earlier turns by default, trimmed to 80% of the target model's context window. Switch to stateless comparison per session. A context meter shows usage, and shows "?" instead of a made-up percentage when the limit is unknown. |
| 📚 **Local RAG** | Upload files and index them on-device (onnxruntime-web embeddings + hnswlib-wasm). Nothing leaves the machine. |
| 💾 **Dual persistence** | IndexedDB (Dexie) for fast queries, plus human-readable Markdown session folders on disk that can rebuild the database if it is lost. |
| 🔐 **Keys stay yours** | Desktop: OS keychain. Web: AES-GCM encrypted in IndexedDB. No server, no accounts, no telemetry. |
| 🌍 **Built for Arabic** | RTL-first UI, Arabic-aware token estimation, and a strict i18n layer (CLDR plurals, enforced key parity). Adding a language is one resource file. |

**Providers:** OpenRouter · Google Gemini · MiniMax (intl) · OpenCode Go

## Architecture

```mermaid
flowchart LR
  UI["React UI (RTL)<br/>composer · result cards · settings"] --> CC["Chat controller<br/>turn builder · context gate"]
  CC -->|"parallel streams"| T["Transport<br/>Vercel AI SDK"]
  T --> OR[OpenRouter]
  T --> GG[Gemini]
  T --> MM[MiniMax]
  T --> OC[OpenCode Go]
  CC --> DB[("Dexie / IndexedDB")]
  CC --> MD["Markdown session folders<br/>Documents/Shura"]
  CC --> RAG["Local RAG<br/>ONNX embeddings + HNSW"]
  subgraph Desktop["Tauri 2 shell (optional)"]
    K[OS keychain]
    H["http plugin: no CORS"]
    F["fs plugin: scoped to $DOCUMENT/Shura"]
  end
  T -.-> H
  MD -.-> F
```

- **No backend.** The browser or Tauri webview calls the providers directly.
- **Tauri 2 shell** adds CORS-free transport, real file writes under `Documents\Shura`, and keychain storage. Capabilities are allow-listed in `src-tauri/capabilities/default.json`.
- **Design decisions** are recorded as ADRs in [`docs/adr`](docs/adr): session persistence, operation identity and recovery, embedding identity, desktop CSP, and i18n enforcement.

## Quick start

```bash
pnpm install
pnpm dev
```

Open the local URL, open **Settings** (الإعدادات), paste a key for any provider and press the live test, then start a session and add models. Requires **Node 24+** and **pnpm 11+**.

Desktop build (Rust + WebView2):

```bash
pnpm tauri dev
pnpm tauri:build:windows
```

Full release gate:

```bash
pnpm check:all
pnpm build && pnpm test:e2e:browser
```

## بالعربية

تطبيق دردشة محلي مع نماذج الذكاء الاصطناعي، يميّزه **الإرسال المتوازي**: سؤال واحد يُوجَّه في اللحظة نفسها إلى عدة مزودين/نماذج تختارها، فتظهر النتائج في بطاقات مستقلة قابلة للمقارنة. التطبيق يتواصل مباشرة من جهازك إلى المزودين بمفاتيح API خاصة بك — **لا باك-إند ولا خادم وسيط إطلاقًا**. الواجهة عربية RTL.

**المزودون الأربعة:** OpenRouter · Google Gemini · MiniMax (intl) · OpenCode Go.

**الإصدار:** 0.1.0 (أول إصدار مُعتَّمَد بعد جولة التعزيز؛ رقم نسخة `package.json` و`src-tauri/tauri.conf.json` متطابقان).

## ما التطبيق

- **الإرسال المتوازي بوضعيه:** سؤال موحّد للجميع، أو سؤال مخصص لكل نموذج (مع قاعدة توريث ثلاثية: الموحد + المخصص يُلحق بفاصل، وبدون موحد يعمل المخصص فقط).
- **بث مباشر (Streaming):** النتائج تُكتب حيًّا في بطاقة لكل مزود، مع تبديل عمودي/أفقي يُحفظ اختياره.
- **حفظ مزدوج:** قاعدة بيانات محلية (Dexie/IndexedDB) للفهرسة السريعة + مجلدات Markdown على القرص (دائمة، مقروءة بالبشر، قابلة للاسترجاع عند فقدان القاعدة).
- **زر «استخرج خلاصة»:** يرسل نتائج آخر تمرّة إلى النموذج الأساسي للجلسة ويعيد خلاصة مركبة.
- **مؤشر الكونتيكست** داخل مربع الإدخال + عدّاد توكنز/تكلفة لكل بطاقة.
- **وضع السياق لكل جلسة (المهمة 4):** الافتراضي **stateful** — الإرسال يتضمن الأدوار المكتملة السابقة من الجلسة نفسها؛ والتحول إلى **«مقارنة stateless»** (إرسال السؤال الحالي وحده) اختيار صريح يُثبَّت في الجلسة. يُقصّ أقدم الأدوار المكتملة ضمن ميزانية 80% من حد سياق الموديل المستهدف (من تعريفه الفعلي؛ فإن غاب الحد يعرض المؤشر علامة جهل «؟» لا نسبة كاذبة)، والسؤال الحالي لا يُسقط أبدًا.
- **غلافان:** ويب (Vite + React) واختياريًا سطح مكتب (Tauri 2) لنقل بلا CORS وكتابة ملفات حقيقية.

## سطح المكتب (Tauri 2)

```bash
pnpm tauri dev      # نافذة تطوير
pnpm tauri build    # بناء إنتاج
```

- الغلاف الأصلي يمنح: **نقلًا بلا CORS** (عبر إضافة `http`) و**كتابة ملفات حقيقية** تحت `Documents\Shura` (عبر إضافة `fs`) — بصلاحيات محصورة في `src-tauri/capabilities/default.json`.
- **ملاحظة بيئة الرابط (هذا الجهاز):** rustc يمسك تلقائيًا `link.exe` 14.16 (VC2017) من ضمن مجموعات MSVC المتعددة فيفشل البناء (LNK2001). البناء يتطلب بيئة **vcvars64** (x64 Native Tools) + متغير `CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_LINKER` إلى `link.exe` **14.42** — الخطوات الدقيقة في [`docs/environment.md`](docs/environment.md).
- الحزمة الناجحة على هذا الجهاز: **NSIS** (`shura_0.1.0_x64-setup.exe`). هدف **MSI** يفشل لأن WiX 3 يتطلب .NET Framework 3.5 الغائب هنا.

## مكان الحفظ

- الافتراضي: **`Documents\Shura`** — جلساتك تحت `Documents\Shura\sessions\<مجلد الجلسة>\` ويتضمن كل مجلد:
  - `session.md` — نص الجلسة المقروء بالبشر (قسم تمرّة لكل إرسال)؛
  - `meta.json` — بيانات الجلسة (يعيد الاسترجاع بناءها منه)؛
  - ملف لكل نتيجة نموذج.
- عند فقدان القاعدة أو من جهاز آخر: الاسترجاع تلقائي من المجلدات عند الإقلاع (سطح المكتب) فقط.
- القاعدة المحلية (Dexie) تحفظ الجلسات والرسائل والاستهلاك والإعدادات في IndexedDB المتصفح/الغلاف.

## الأمان

- **المفاتيح محلية فقط:** في نسخة سطح المكتب تُحفظ في خزنة نظام التشغيل، وفي نسخة الويب في سجل IndexedDB مشفّر بـ AES-GCM؛ ولا تغادر جهازك إلا داخل نداء مباشر إلى المزود صاحبها.
- **لا خادم:** لا باك-إند، لا حسابات، لا تتبع — كل الاتصالات من جهازك إلى المزودين مباشرة.
- **صلاحيات محصورة في Tauri:** نطاقات النقل الخمسة (المزودون الأربعة + `huggingface.co` لنموذج التضمين المحلي)، وستة أذونات ملفات بنطاق `$DOCUMENT/Shura/**` فقط — أي مسار آخر يُنكر. (ملاحظة: الرمز الصحيح في Tauri هو `$DOCUMENT` بحرف مفرد، وهو ما تستخدمه `capabilities/default.json`.)
- **مفاتيح سطح المكتب في خزنة نظام التشغيل** عبر أوامر Tauri. **على الويب** تُخزَّن مفاتيح التشفير في IndexedDB؛ وهي تحمي من مواقع أخرى، لكنها **ليست حماية من كود يعمل في أصل الصفحة** — أي شيفرة في الصفحة أو امتداد متصفح أو من يملك الجهاز ويفتح DevTools يستطيع قراءتها. الاستعمال الآمن للمفاتيح الحقيقية هو **نسخة سطح المكتب**؛ النسخة المتصفّحة للتجربة أو لمفاتيح محدودة الصلاحيات. (نموذج التهديد المعتمد: ADR 0001 §5.)
- لا أسرار في المستودع؛ لا `env` مطلوب للتشغيل.

## القيود المعروفة

1. **تقدير الكونتيكست تقريبي:** الحساب **واعٍ بالنص العربي** — ‎2.5 حرف/توكن للعربي و4 للاتيني، والنتيجة موزونة بنسبة الخلط مع تقريب لأعلى (`src/lib/tokens/estimate.ts`، وهو المصدر الوحيد الذي تقرأ منه بوابة السياق ومؤشر الكونتيكست ومقسّم RAG). رقم إرشادي، ليس فاتورة الاستهلاك الدقيقة للمزود.
2. **موديلات Google وMiniMax ثابتة القائمة** (مضمنة في سجل المزودين، قابلة للتحديث يدويًا)؛ وقائمتا OpenRouter وOpenCode Go تُجلبان حيًّا مع كاش (سجل المزودين: `modelsSource`).
3. **CORS يمنع OpenCode Go في وضع الويب:** نتائج فحص المتصفح المباشر (من وثيقة التصميم §4.3، 2026-09-05):

   | المزود | نداء المتصفح المباشر |
   |---|---|
   | OpenRouter | ✅ مفتوح (Access-Control-Allow-Origin: *) |
   | Gemini | ✅ مفتوح |
   | MiniMax | ✅ مفتوح (يُعاد التحقق بنداء فعلي في المرحلة 0) |
   | OpenCode Go | ❌ محجوب (OPTIONS: 404 بلا ترويسات CORS؛ POST: 401 بلا ترويسات) |

   ⇒ استخدام OpenCode Go يتطلب **غلاف سطح المكتب**؛ في وضع الويب يظهر بحالة «يتطلب تطبيق سطح المكتب» بدل فشل صامت.
4. هدف **MSI** في حزم Tauri معطل على هذا الجهاز (غياب .NET 3.5) — استخدم NSIS.
5. **ميزانية الحزمة الأساسية:** <!--G:bundle.entry.kb-->1,112.80<!--/G--> kB مقابل حدّ 1,200,000 بايت (هامش ≈ <!--G:bundle.headroom.kb-->87.20<!--/G--> kB). اتّسع الهامش بعد فصل شيفرة RAG إلى حزم منفصلة، لكن `dist/index.html` يحمّلها مسبقًا عبر `modulepreload` لأن نقاط دخول RAG تُستورد ساكنًا، فالحمولة الفعلية عند الإقلاع <!--G:bundle.eager.kb-->1,331.37<!--/G--> kB — مسجّلة كـLV-09 في المراجعة وتُغلق في T1.3 Step 9؛ والحدّ نفسه لم يُخفَّض ولم يُرفع — انظر `docs/environment.md` §8.2.
6. **اختبار المتصفح يغطّي نسخة الويب (المزوّد وهمي)، لا غلاف سطح المكتب:** الكتابة على القرص فعليًا تحت `$DOCUMENT/Shura` واسترجاعها بعد فقدان القاعدة لم يُختبرا آليًا — تبقى `SKIPPED: متطلب بشري`.

## تغطية جديدة من اختبار المتصفح (المهمة 11)

بقيت بنود القائمة أعلاه مغطّاة آليًا في المتصفح نفسه على بناء الإنتاج (بمزوّد وهمي داخلي، بلا مفتاح
وبلا شبكة خارجية)؛ هذه أرقام `e2e/app.spec.ts`:

| البند | السيناريو الآلي |
|---|---|
| 1 (جزئيًا) | «مسودة جلستين لا تتسرّب»: جلستان بموديلين مختلفين، وأول مسودة تظهر في سياقها الثانية لا — ناقل الإرسال نفسه، لكن ببطاقة واحدة بدل ثلاثة (السيناريو الحرفي بثلاثة نماذج لم يُنفَّذ آليًا). |
| 6 | «إجابة متوقّفة جزئيًا وحالتها تنجو من إعادة التحميل» + «جلسة محذوفة لا تعود»: إعادة تحميل حقيقية على البناء الإنتاجي مع تحقق من حالة IndexedDB. |
| جديد | «متابعة stateful ترسل السجل للمزوّد»: جسم الطلب الثاني يجب أن يحمل سؤال المستخدم الأول وردّه. **هذا الاختبار كشف عطلًا حقيقيًا**: كان السؤال يختفي من المحادثة ولا يُرسل كسياق (انظر `docs/environment.md` §10). |
| جديد | «إعادة المحاولة تعيد السؤال المخصص التاريخي لا مسودة المؤلف». |
| جديد | «لا يخرج أي طلب خارجي»: كل طلب لغير `127.0.0.1:4317` يُسجَّل ويُلغى، والاختبار يفرض فراغ السجل. |
| جديد | «واجهة الإعدادات»: مفتاح وهمي، `Escape` يغلق و`Tab` يعيد التركيز، والمفتاح لا يظهر في سجل الإعدادات المحفوظ. |
| جديد | «التخطيط»: تنقّل بلوحة المفاتيح، وعرض 390px بلا تمرير أفقي، وحجب موارد Markdown البعيدة. |
