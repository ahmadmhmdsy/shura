# شورى (Shura)

تطبيق دردشة محلي مع نماذج الذكاء الاصطناعي، يميّزه **الإرسال المتوازي**: سؤال واحد يُوجَّه في اللحظة نفسها إلى عدة مزودين/نماذج تختارها، فتظهر النتائج في بطاقات مستقلة قابلة للمقارنة. التطبيق يتواصل مباشرة من جهازك إلى المزودين بمفاتيح API خاصة بك — **لا باك-إند ولا خادم وسيط إطلاقًا**. الواجهة عربية RTL.

**المزودون الأربعة:** OpenRouter · Google Gemini · MiniMax (intl) · OpenCode Go.

## ما التطبيق

- **الإرسال المتوازي بوضعيه:** سؤال موحّد للجميع، أو سؤال مخصص لكل نموذج (مع قاعدة توريث ثلاثية: الموحد + المخصص يُلحق بفاصل، وبدون موحد يعمل المخصص فقط).
- **بث مباشر (Streaming):** النتائج تُكتب حيًّا في بطاقة لكل مزود، مع تبديل عمودي/أفقي يُحفظ اختياره.
- **حفظ مزدوج:** قاعدة بيانات محلية (Dexie/IndexedDB) للفهرسة السريعة + مجلدات Markdown على القرص (دائمة، مقروءة بالبشر، قابلة للاسترجاع عند فقدان القاعدة).
- **زر «استخرج خلاصة»:** يرسل نتائج آخر تمرّة إلى النموذج الأساسي للجلسة ويعيد خلاصة مركبة.
- **مؤشر الكونتيكست** داخل مربع الإدخال + عدّاد توكنز/تكلفة لكل بطاقة.
- **وضع السياق لكل جلسة (المهمة 4):** الافتراضي **stateful** — الإرسال يتضمن الأدوار المكتملة السابقة من الجلسة نفسها؛ والتحول إلى **«مقارنة stateless»** (إرسال السؤال الحالي وحده) اختيار صريح يُثبَّت في الجلسة. يُقصّ أقدم الأدوار المكتملة ضمن ميزانية 80% من حد سياق الموديل المستهدف (من تعريفه الفعلي؛ فإن غاب الحد يعرض المؤشر علامة جهل «؟» لا نسبة كاذبة)، والسؤال الحالي لا يُسقط أبدًا.
- **غلافان:** ويب (Vite + React) واختياريًا سطح مكتب (Tauri 2) لنقل بلا CORS وكتابة ملفات حقيقية.

## المتطلبات

- **Node 24+** (طُوِّر واختُبر على 24.18.0).
- **pnpm** (طُوِّر واختُبر على 11.25.0؛ `devEngines` يشترط `^11.7.0`).
- **اختياري — غلاف سطح المكتب (Tauri 2):** Rust (اختُبر على rustc 1.98.0) + WebView2 (متوفر افتراضيًا في ويندوز 10/11). على هذا الجهاز تحديدًا انظر ملاحظة بيئة الرابط أدناه ووثّقها في [`docs/environment.md`](docs/environment.md).

## التشغيل (وضع الويب)

```bash
pnpm install
pnpm dev
```

ثم افتح العنوان المحلي الذي يطبعه Vite، وأدخل مفاتيح المزودين من **شاشة الإعدادات** داخل التطبيق (زر الإعدادات في الشريط الجانبي): لكل مزود بطاقة مفتاح مع **اختبار حيّ** للمفتاح، واختيار النموذج الأساسي، ومهلة النداء، ومسار الحفظ.

أوامر التحقق:

```bash
pnpm typecheck && pnpm lint && pnpm test && pnpm build
```

آخر سلسلة تحقق معتمدة: **PASS كاملًا — 155/155 اختبارًا عبر 23 ملف اختبار** (vitest، بلا شبكة حقيقية في الاختبارات — fetch مزيّف محقون إلى طبقة النقل).

## سطح المكتب (Tauri 2)

```bash
pnpm tauri dev      # نافذة تطوير
pnpm tauri build    # بناء إنتاج
```

- الغلاف الأصلي يمنح: **نقلًا بلا CORS** (عبر إضافة `http`) و**كتابة ملفات حقيقية** تحت `Documents\Shura` (عبر إضافة `fs`) — بصلاحيات محصورة في `src-tauri/capabilities/default.json`.
- **ملاحظة بيئة الرابط (هذا الجهاز):** rustc يمسك تلقائيًا `link.exe` 14.16 (VC2017) من ضمن مجموعات MSVC المتعددة فيفشل البناء (LNK2001). البناء يتطلب بيئة **vcvars64** (x64 Native Tools) + متغير `CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_LINKER` إلى `link.exe` **14.42** — الخطوات الدقيقة في [`docs/environment.md`](docs/environment.md).
- الحزمة الناجحة على هذا الجهاز: **NSIS** (`shura_0.1.0_x64-setup.exe`). هدف **MSI** يفشل لأن WiX 3 يتطلب .NET Framework 3.5 الغائب هنا.

## مكان الحفظ

- الافتراضي: **`Documents\Shura`** — جلساتك تحت `Documents\Shura\sessions\<مجلد الجلسة>\` ويتضمن كل مجلد:
  - `session.md` — نص الجلسة المقروء بالبشر (قسم تمرّة لكل إرسال)؛
  - `meta.json` — بيانات الجلسة (يعيد الاسترجاع بناءها منه)؛
  - ملف لكل نتيجة نموذج.
- عند فقدان القاعدة أو من جهاز آخر: الاسترجاع تلقائي من المجلدات عند الإقلاع (سطح المكتب) فقط.
- القاعدة المحلية (Dexie) تحفظ الجلسات والرسائل والاستهلاك والإعدادات في IndexedDB المتصفح/الغلاف.

## الأمان

- **المفاتيح محلية فقط:** تُكتب في قاعدة Dexie على جهازك ولا تغادره إلا داخل نداء مباشر إلى المزود صاحبها.
- **لا خادم:** لا باك-إند، لا حسابات، لا تتبع — كل الاتصالات من جهازك إلى المزودين مباشرة.
- **صلاحيات محصورة في Tauri:** نطاقات المزودين الأربعة للنقل، و`$DOCUMENTS/Shura/**` فقط للملفات — أي مسار آخر يُنكر.
- لا أسرار في المستودع؛ لا `env` مطلوب للتشغيل.

## القيود المعروفة

1. **تقدير الكونتيكست تقريبي:** الحساب `chars/4` مع تقريب لأعلى — رقم إرشادي، ليس فاتورة الاستهلاك الدقيقة للمزود.
2. **موديلات MiniMax وOpenCode Go ثابتة القائمة** (مضمنة في سجل المزودين، قابلة للتحديث يدويًا)؛ قائمة OpenRouter وحدها تُجلب حيًّا مع كاش.
3. **CORS يمنع OpenCode Go في وضع الويب:** نتائج فحص المتصفح المباشر (من وثيقة التصميم §4.3، 2026-09-05):

   | المزود | نداء المتصفح المباشر |
   |---|---|
   | OpenRouter | ✅ مفتوح (Access-Control-Allow-Origin: *) |
   | Gemini | ✅ مفتوح |
   | MiniMax | ✅ مفتوح (يُعاد التحقق بنداء فعلي في المرحلة 0) |
   | OpenCode Go | ❌ محجوب (OPTIONS: 404 بلا ترويسات CORS؛ POST: 401 بلا ترويسات) |

   ⇒ استخدام OpenCode Go يتطلب **غلاف سطح المكتب**؛ في وضع الويب يظهر بحالة «يتطلب تطبيق سطح المكتب» بدل فشل صامت.
4. هدف **MSI** في حزم Tauri معطل على هذا الجهاز (غياب .NET 3.5) — استخدم NSIS.
